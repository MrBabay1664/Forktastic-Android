<h1 align="center">Meshtastic Android App (Fork)</h1>

This is a tool for using Android (and Compose Desktop) with open-source mesh radios. For more information see his webpage: [meshtastic.org](https://www.meshtastic.org). If you are looking for the device side code, see [here](https://github.com/meshtastic/firmware).

Original meshtastic android app repository and more detailed description is here: [meshtastic/Meshtastic-Android](https://github.com/meshtastic/Meshtastic-Android)
